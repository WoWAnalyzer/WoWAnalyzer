# Static local-log fixture

`static-local-combat-log.txt` is synthetic test data written for this repository from the
documented Retail advanced-combat-log field layout. It contains no player account, copied report,
or third-party combat-log data, so it may be redistributed under the repository license.

The fixture deliberately includes two encounters, multiple participants, a pet, non-ASCII and
quoted names, combatant information, resources, casts, an aura, damage, healing, an absorb, a miss,
a death, and one unsupported record. It is minimized for the browser import journey rather than
intended to model a competitive parse.
